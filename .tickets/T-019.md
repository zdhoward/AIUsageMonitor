# Stock ticker (future idea)

A display page showing a few chosen symbols: price, day change (green/red) and a small intraday sparkline. It could also be a scrolling "news ticker" strip along the bottom of other pages.

## Fits the existing design

- **The PC fetches; the display draws.** It would be a new `service/aimon/sources/` module that polls quotes every 1-5 minutes and sends a small `{"t":"stk",...}` line (symbol, price, change %, 24-48 sparkline points). This works like the System page, and the display needs no Wi-Fi or API key.
- **No secrets in the repo.** Any API key lives in `aimon.config.json` (git-ignored) or an environment variable, never in profiles or the firmware. Prefer a no-key source first.
- The profile picks symbols and the layout: list, a single big symbol, or a scrolling strip. The Studio gets a page card.

## Questions to settle before building

- **Data source** and its terms: free tier, rate limits, delay (most free quotes are 15 min delayed), and whether redistributing them on a public repo's defaults is allowed.
- Which symbols, and whether crypto or indices count.
- Market-closed behaviour: show the last close, dim the page, or skip it in the rotation.
- Scrolling ticker strip versus a static page, or both.

Not planned for now; recorded on the owner's request (2026-10-25).
