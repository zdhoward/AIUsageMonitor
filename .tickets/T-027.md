Spec: docs/CPAMC_HOME.md.

- New `service/aimon/sources/cpamc.py`: poll `GET /v0/management/auth-files` about every 30s using `CPAMC_MANAGEMENT_KEY` from gitignored `service/.cpamc.env` (env var wins). Never log the key or account emails.
- Ignore disabled accounts. Group active accounts by `provider`.
- Normalize windows to `(label, used%, reset_at, window_minutes)`. Claude: `Unified-5h`/`-7d` utilization. Codex: Primary/Secondary `Used-Percent`/`Reset-At`/`Window-Minutes`. Label each window from its length (5h, 7d, 30d, ...), so 30-day-only providers (e.g. Mistral Vibe) get a real line instead of `--`.
- Pool each window as sum(remaining)/(100*N). Reset = soonest future reset in the group. A past reset means the account counts as refilled (100%) and is marked stale.
- A quota cooldown with no signals counts as 0% remaining, with the soonest `retry_at` as the reset.
- Attention flags: status not active, `unavailable`, non-empty `status_message`, refresh failure, CPAMC unreachable. Exhausted quota never raises a flag.
- Extend the snapshot JSON and docs/PROTOCOL.md with a compact `proxy` message: groups, active-account count, windows, attention flag, proxy_up, data age.

## Interface
`cpamc.parse(auth_files: dict, now: float) -> dict`, a pure function returning
`{"proxy_up": True, "groups": [{"name": "claude", "n": 2, "attn": False,
"windows": [{"label": "5h", "rem": 37, "reset": <epoch>}, ...]}]}`.
`CpamcSource.poll()` does the HTTP call, returns `{"proxy_up": False, ...last groups}` on failure, and never raises.

Sample input (2 Claude accounts, 1 disabled Codex):
```json
{"files":[
 {"provider":"claude","status":"active","disabled":false,"unavailable":false,"status_message":"","cooldowns":[],
  "quota":{"signals":{"Anthropic-Ratelimit-Unified-5h-Utilization":"0.53","Anthropic-Ratelimit-Unified-5h-Reset":"2000003600","Anthropic-Ratelimit-Unified-7d-Utilization":"0.64","Anthropic-Ratelimit-Unified-7d-Reset":"2000300000"}}},
 {"provider":"claude","status":"active","disabled":false,"unavailable":false,"status_message":"","cooldowns":[],
  "quota":{"signals":{"Anthropic-Ratelimit-Unified-5h-Utilization":"0.73","Anthropic-Ratelimit-Unified-5h-Reset":"2000001800","Anthropic-Ratelimit-Unified-7d-Utilization":"0.83","Anthropic-Ratelimit-Unified-7d-Reset":"2000100000"}}},
 {"provider":"codex","status":"disabled","disabled":true,"cooldowns":[],"quota":{"signals":{}}}]}
```
With now=2000000000 the result must have one group, claude, n=2, 5h rem 37 reset 2000001800, 7d rem 27 reset 2000100000.
