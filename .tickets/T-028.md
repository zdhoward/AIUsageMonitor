Depends on T-027. A new "Proxy" page in the page registry, Studio and profile, set as the default Home. Console stays selectable and configurable.
- Same 3x2 tile grid, rings and colours as Console (mockup A in docs/CPAMC_HOME.md). Header `PROXY (n)`, `×N` beside each group name.
- Outer ring is the shorter window, inner the longer. Each line takes its label from the window (5h/7d/30d). A missing window shows `--`.
- Unknown (no data) uses the dashed ring. Cooldown shows a 0% ring plus the countdown.

## Serial message (contract; T-027/T-032 must emit exactly this)
A separate line, like `sys`, about every 30s:
```json
{"t":"proxy","up":1,"age":12,"attn":0,
 "g":[{"n":"Claude","c":2,"a":0,"ly":"r","p":[{"l":"Claude","w":[{"l":"5h","r":13,"z":1793384800},{"l":"7d","r":25,"z":1793509200}]}]},
      {"n":"Codex","c":1,"a":0,"ly":"r","p":[{"l":"Codex","w":[{"l":"5h","r":100,"z":1793400595},{"l":"7d","r":26,"z":1793798945}]}]},
      {"n":"Antigrav","c":2,"a":0,"ly":"m","p":[{"l":"Flash","w":[{"l":"5h","r":100,"z":0},{"l":"7d","r":50,"z":1793641450}]},{"l":"Cl/GPT","w":[{"l":"5h","r":100,"z":0},{"l":"7d","r":75,"z":1793900000}]},{"l":"Argon","w":[{"l":"7d","r":50,"z":1793641450}]}]},
      {"n":"xAI","c":1,"a":0,"ly":"r","p":[{"l":"xAI","w":[{"l":"7d","r":-1,"z":1793836800}]}]}]}
```
- `up` proxy reachable, `age` seconds since the last good poll, `attn` global danger flag, `c` active accounts, `a` per-group danger flag.
- `ly`: `r` normal tile, `m` multi-pool double-wide tile. `p` pools (max 3); `w` windows (max 2: outer is the shorter, inner the longer). `r` remaining 0-100 or -1 unknown. `z` the next reset epoch, 0 if none.
- Max 6 groups. Slot order: groups in order, then the System card in the next free slot (T-029). `m` spans 2 columns.
