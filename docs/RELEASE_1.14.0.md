# v1.14.0 — Studio settings and release hardening

Scene Studio now has a dedicated service Settings tab, clearer generator headings, and hides sky controls that do not affect generator scenes. Settings saves preserve private configuration keys, validate values against the service's supported ranges, and replace the config atomically. Restart the service to apply settings; saving never flashes or restarts the display.

All Studio POST endpoints now require JSON and a loopback Host with matching origin/port. Request bodies are bounded and filesystem failures do not return private paths. Studio remains a local application, not a network-authenticated administration service.

This release also publishes the prior compact Console grid, direct Gemini quota source, cheap two-second quota reads, cached transcript aggregates, quota-transition history and configurable one-hour pre-reset wake. The owner reports the new wake behavior works well. Argon remains unknown until an independent measurement source is available; the owner's report that it is exhausted is not substituted for telemetry.
